# TORCLIX FIT

**Personal Performance System**

TORCLIX FIT is a Telegram-first fitness product built around one core mechanic: **NEXT MOVE** — a personalized daily decision about the best next action for the user's goal.

## Product pillars
- NEXT MOVE
- Fitness Twin
- Adaptive Training
- Recovery
- Nutrition
- AI Decision Center
- Progress / EVOLVE
- Missions
- Squads & Duels
- Telegram Mini App + Bot
- Premium performance design

## Design direction
Obsidian / graphite / titanium gold / ice blue. Cinematic, premium, restrained, performance-oriented.
